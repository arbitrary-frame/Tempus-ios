# Tempus Roadmap

## MVP Complete ✅
- Workout logging with exercises, sets, weights, reps
- Workout routines with emoji icons
- Exercise library with muscle groups
- Drop set support
- Workout history with editing
- Data export (JSON)
- Dark/light mode
- Basic analytics
- Settings screen
